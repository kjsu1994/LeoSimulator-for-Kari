Rebuild
  Windows, Python 3.12, and WebView2 Runtime are used for development.
  python -m pip install -r requirements-build.txt
  For the native build only, WSL Ubuntu with g++-mingw-w64-x86-64 is required.
  python engine/build.py
  python -m PyInstaller --noconfirm sim-ui.spec
  python build_release.py
  The native executable can be replaced with a rebuilt compatible version;
  no signatures or authentication restrict replacement. Compilers are not
  required to run the delivered application.

Changes dated 2026-11-17: the supplied leo-feature-csib-ds-model pure C++
Routing_Core mcsr and congestion headers are preserved byte-for-byte under
engine/vendor/routing/. SHA-256 fingerprints: engine/vendor/routing-origin.json.
Reference core tests and their test-only Walker fixture are included under
engine/tests/. They carry the supplied FLoRaSat project license; the combined
program continues to be distributed under GPL-3.0-only with complete source.
OMNeT++ and INET runtime libraries and headers are not shipped or required.
The independent adapter, packet scheduler, INI normalization, asynchronous local
runner and recorded-metric replay are modifications, not an upstream release.

Research adapter revision 3: shared frozen physical inputs, offered-load metrics,
explicit experimental packet control protocol, packet delay variation, counters
and v3 replay are local modifications. The supplied MCSR core headers remain
unchanged. The new control wire model is not a claim of paper/protocol equivalence.

Research adapter revision 4: explicit control unicast, frame segmentation/reassembly, independent resynchronization and frozen common SRD targets. Original routing cores remain unchanged.
